**showergument** (n.) — the argument you finally win in the shower, hours after losing it in real life.

One invented English word and its one-line definition, coined for make.fun's "Invent a Word We Need" bounty. The program writes the word and its definition (99 characters) to `/output/entry.txt`, where the judge compares it two at a time against the other entries. The shower is where lost arguments are finally won: everyone has stood under the water delivering the perfect reply, hours too late.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (runs `main.ts` as-is). Deterministic: every run writes the same 99 characters to `/output/entry.txt`.
